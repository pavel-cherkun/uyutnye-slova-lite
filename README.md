# Уютные слова — простая версия

Гипер-казуальная мобильная игра в слова. Три игры одной цепочкой:

1. **Блоки** — сбивай блоки и добывай буквы.
2. **Эрудит** — собирай из букв слова: каждое слово становится вещью-эмодзи (458 вещей).
3. **Три в ряд** — вещи становятся фишками, вещи-цели сгорают, за победу — буквы и шанс на редкую вещь. 100 уровней в 10 главах, каждый 10-й — босс.

Вверху — сколько букв и вещей; по нажатию открывается инвентарь. Прогресс хранится в браузере.

Запуск локально: `node serve.mjs` → http://localhost:8765
